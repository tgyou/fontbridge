FontBridge user fonts

No font files are included with FontBridge.

1. Place your own .ttf or .otf files in this folder.
2. Fully exit and restart World of Warcraft after adding new files.
3. Open /fb and enter a display name and filename to add each font.

Example filename: MyFont.ttf
You can also reference a font in another addon using its full Interface path.
Example path: Interface\AddOns\MyMedia\Fonts\MyFont.ttf

FontBridge stores your registered fonts and area settings in SavedVariables.
It does not require FontManager. Removing a list entry does not delete its file.
Font glyph coverage depends on the font you provide.

FontBridge 사용자 폰트

FontBridge 배포본에는 폰트 파일이 포함되지 않습니다.

1. 사용할 .ttf 또는 .otf 파일을 이 폴더에 직접 넣습니다.
2. 새 파일을 추가한 뒤에는 게임을 완전히 종료하고 다시 실행합니다.
3. /fb 창에서 표시 이름과 확장자를 포함한 파일명을 입력해 등록합니다.

예: MyFont.ttf
다른 애드온의 폰트 파일을 전체 Interface 경로로 참조할 수도 있습니다.
FontManager는 필요하지 않습니다. 글자 지원 범위는 사용자가 넣은 폰트에 따라 다릅니다.
